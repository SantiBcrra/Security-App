# Security App

Sistema de Seguridad e Higiene (SaaS multi-empresa). PHP 8.2+ sin framework + MySQL.

- Plan completo por etapas: [PLAN.md](PLAN.md)
- Convenciones, decisiones y checklist de deploy: [CLAUDE.md](CLAUDE.md)

## Instalación (igual en XAMPP y en el hosting)
1. Copiar los archivos (FTP, administrador de archivos o GitHub Actions).
2. Crear una base MySQL vacía desde el panel.
3. Abrir `/install/check.php` y verificar que todo esté en verde.
4. Abrir `/install` y completar el instalador web (Etapa 1).
